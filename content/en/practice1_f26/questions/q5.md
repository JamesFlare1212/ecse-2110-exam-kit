## Question

Show that only 1-phase circuits have the double frequency component of power but not the balanced 3-phase circuits. Include detailed steps.

## Guide

Write each phase's voltage and current using peak amplitudes and a common load angle. Apply product-to-sum, then explicitly add the three double-frequency cosines. The cancellation concerns total balanced three-phase power, while each phase separately still pulsates.

## Part a

Show that only 1-phase circuits have the double frequency component of power but not the balanced 3-phase circuits. Include detailed steps.

### Solution

Start with the definition $p(t)=v(t)i(t)$ and the reference sheet's [product-to-sum identity](formula:product-to-sum). Let $V_m,I_m$ be peak amplitudes, $\alpha$ the voltage phase and $\phi$ the current lag:

$$
v=V_m\cos(\omega t+\alpha),\quad i=I_m\cos(\omega t+\alpha-\phi),\quad
\cos A\cos B=\tfrac12[\cos(A-B)+\cos(A+B)]
$$

Substitute the actual arguments to obtain the single-phase power:

$$
\begin{aligned}
p_{1\phi}(t)&=V_mI_m\cos(\omega t+\alpha)\cos(\omega t+\alpha-\phi)\\
&=\frac{V_mI_m}{2}\left[\cos\phi+\cos(2\omega t+2\alpha-\phi)\right]
\end{aligned}
$$

For a balanced system choose phase displacements $0,-120^\circ,+120^\circ$ and put $u=2\omega t-\phi$. The three ripple terms sum to

$$
\begin{aligned}
\Sigma&=\cos u+\cos(u-240^\circ)+\cos(u+240^\circ)\\
&=\cos u+2\cos u\cos240^\circ\\
&=\cos u+2\cos u(-\tfrac12)=0
\end{aligned}
$$

The constant term occurs once per phase. Since $V=V_m/\sqrt2$ and $I=I_m/\sqrt2$, their sum agrees with the [three-phase real-power formula](formula:three-phase-power):

$$
\boxed{p_{1\phi}=\frac{V_mI_m}{2}\left[\cos\phi+\cos(2\omega t+2\alpha-\phi)\right],\qquad
p_{3\phi}=\frac{3V_mI_m}{2}\cos\phi=3VI\cos\phi}
$$

The single-phase expression contains a $2\omega$ component for nonzero sinusoidal voltage and current. In the balanced three-phase sum it cancels exactly, although each phase retains it.

### Source correction

PDF page 7 drops the factor $1/2$ while still using peak symbols $V_m,I_m$, and boxes $3V_mI_m\cos\phi$. The correct peak-amplitude result is $3V_mI_m\cos\phi/2$; $3VI\cos\phi$ uses RMS amplitudes. Some intermediate cosine expansions also have inconsistent sine signs. The explicit symmetric sum above avoids those errors. “Only 1-phase circuits” is interpreted within the question's comparison: unbalanced three-phase systems can also have double-frequency total-power ripple.
