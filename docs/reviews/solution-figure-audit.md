## 首轮最多 8 项优先建议

以下按“教学误区严重程度＋可独立验收”挑选，不等于所有 P1 必须同时实施。每项先做一题的完整双语四版本，再考虑类似题；复用的是构图方法，不是跨语言／跨试卷文件回退。

1. **`p2-f26-q3`：有符号能流图。** 投入较小、收益很高。首先把“3512.259 W＋715.209 W→4227.468 W 电枢铜耗”画清；验收必须同时满足 KVL、被动符号约定和功率守恒，尤其不能标成电网再生制动。
2. **`p2-f26-q4`：现有波形加导通路径和状态带。** 优先修补读者从器件到时间图的认知断层，而非再加曲线。逐区间走通实际 S1D2／S2D1／D1D2；核对 vS1 在 π 开始反压、30° 与 90° 工况分离。
3. **`e1-s25-q4`：Δ 电流相减的完整相量构造。** 一张端子图加一张向量差小图即可解释 √3 与 −30°。先验算三个端子的 KCL，再以 `p1-f26-q6` 的不同阻抗做迁移核对，不能复制数值。
4. **`e2-u00-q5`：电动机相量与 Δ 线／相电流。** 分清正滞后功角与内部电压负相角，a、b 两工况分别标数值，c 不混用。90° 只标理想边界，不加“稳定运行”标记。
5. **`e1-f26-q4`：补偿前后 P–Q 图。** 最容易以小图解决“270 是目标剩余无功，210 才是电容容量”的混淆。同时明确 Y 支路电压，频率缺失仍以假设形式出现。
6. **`p2-f26-q6`：平均值／RMS／额外 4 W 的注解。** 保留既有代表性波形，不重造更漂亮但不自洽的正弦纹波。验收数值用方差分解与平均能量平衡，不从图上猜峰峰值。
7. **`e2-u00-q2` 的 2-7：空间基波抵消。** 用三条空间分量与零合成线，防止读者把同相电流误看成平衡正序。空间三次谐波只能以条件说明出现，不能让图片变成未经证实的 C 选项“标准答案”。
8. **`e2-s25-q3`：换向前后连接状态＋整流波形。** 两个静态状态比装饰性的换向器端视图更有教学价值；固定电刷不动、线圈与铜片转半周、外部极性不变必须同时成立。实际换向过渡仅作边界说明，不虚构时间和火花模型。

其余 P1（如并联 Y／Δ 的单相化、悬浮中性点、同步发电机超前电流、负调整率、三相功率纹波抵消、叠／波绕组计数）仍值得做，但可在首轮验证标注密度与双语维护成本后排期。

## 实现风险与交付条件

### 来源与科学风险

- **旧 renderer 分支不是授权恢复题图。** `scripts/generate_figures.py` 按文章实际引用过滤输出；多个考试 renderer 仍有未挂载的概念图分支。不能把这些分支、旧 `figureCaption`、公式表电路或官方解答图视为“原题本来有图”。新图只能挂 `parts.<原标签>.figure`，题面 `figure: null` 应保持。
- **不能把示意变成题设。** 不增加实际接地、中性导线、绕组极数、槽数、磁化曲线、谐波幅度、惯量或具体电感。若采用归一化量、等效测试电路或代表性模型，图内／相邻说明应明确其身份；所有辅助数字要能由已有条件及已声明模型推导。
- **电机与相量需要独立数值验算。** 每张图先固定电流方向、端电压极性、参考相、相序、角度正方向。发电机 E=V+jXsI，电动机 E=V−jXsI；三角形线电流必须相减。电压／电流分尺度，复平面两轴等比例，功率坐标和电相量坐标不要混称。
- **电流路径比颜色重要。** 交叉无结点、真实结点、SCR 正向、二极管标号与返回通路都要核实。半控桥已有二极管腿提供续流，不增加器件；全控桥负电压片段不能删除。讲义 p23–24 的负载波形与连续电流题的模型不同，应取拓扑和真实公式，不照搬全部曲线。
- **能流须区分端口与内部转换。** `p2-f26-q3` 的 EaI 是内部转换功率；整个带 Ra 的电枢端口仍可净吸收功率。`p2-f26-q6` 的转换功率与铜损采用不同电流统计量。避免漂亮的箭头图暗示所有功率都是机械净输出，或把无功当作持续消耗的能量。
- **歧义不能由制图静默消除。** `e2-u00-q2` 的 2-3／2-6／2-7、Q3 的饱和条件、Q5(c) 的工况、`e2-s25-q5` 的波绕组闭合限制、`e1-f26-q4` 的频率，以及 `p2-f26-q6` 的纹波定义，都须继续保留正文纠错／条件说明。

### 资产、标注与维护风险

- 每张新教学图只显示在相应小问揭示后的解答内；不写回 Question，不增加题目给定量，不合成新的答案卡或用图片代替完整 Markdown 推导。图上可标必要计算量，最终答案强调仍由正文最后的计算承担。
- 两种语言各自拥有 SVG、renderer 配置及说明文本；每种语言同时交付浅色和深色主题。数学字母、单位、符号、物理条件一致，普通标签分别翻译，不能用英文图片回退替代中文版。
- 保留静态 SVG、原题图的来源切换与原始拓扑／视角。来源按钮所需的下方空间不得被新注解侵占；新教学图不能伪装为原图裁剪，也不为它编造原题来源矩形。
- 新图不进入公式栏，讲义推导不伪称 Reference Sheet 原式。组 1 与组 2 的表仍分开，类似效率题也不能跨表补链接。无需添加远程资源、PDF 下载或改变 PDF 跟踪状态。
- 多面板宜纵向排列或控制单图信息量；相量角度与归一化轴清晰，颜色之外用标签／线型编码。半控桥九行波形应增加状态对应而非缩字号塞入一整页教材；深色主题和最终中文 SVG 需目视检查，不能只看英文字体阶段 PNG。
- 受限于每小问的单个 `part.figure`，同一小问需要路径与波形时应设计一张有清晰分区的静态组合图，不擅自扩展 UI／内容 schema。跨小问图示应贴近对应推导，不把所有信息塞到第一小问导致提前泄露后续结果。
