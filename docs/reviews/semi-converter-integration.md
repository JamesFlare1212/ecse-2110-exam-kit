## 图形、模型与数据

`scripts/semi_converter_sprite.py` 将已批准小样的标准 Schemdraw 电路提升为离线资源。各语言的 paper-local renderer 调用辅助资源 hook，生成自己的 `p2-f26-q4-conduction{,-dark}.svg` 以及纯坐标 `.json`。图元以同源外部 SVG `<use>` 引用，未将文件文本注入 DOM。首次接入分别着色标签与导通线；当前彩色修订保留全部中性原线条和可读标签，颜色仅用于测量叠加层，不再把颜色作为导通或节点电位编码。

JSON 仅含 viewBox、57 个原生片段的安全 ID/归属、三条闭合约定电流路线；不是题库或答案来源。构建和客户端均验证版本、有限坐标、边界、闭合路线、唯一片段 ID、合法归属与惰性 SVG；禁止执行性节点、事件处理器与远端资源。完整规范图仍为 19 张，辅助片段不混入题图数量。新增输入与资源清单进入两份 manifest。

运行时算术来自 `src/lib/visualizations/semi-converter-model.mjs`，历史小样复用同一算术。仅支持理想开关、α=30°、已建立的恒定连续负载电流，全部量归一化。左腿 S1/S2，右腿 D1/D2，交流输入下线跨越左腿时不连接。交流电源为教学示意而显式补画在原输入端之间。正半周 S1/D2，负半周 S2/D1，续流 D1/D2；S1 的反向电压在 180° 过零后开始。

## 最新批注：全程播放与连续拖动

按用户进一步说明，移除五档滑杆。现使用原生 shadcn Slider 的线性 0°–360° 连续角度范围，0.1° 输入分辨率不吸附到任何导通边界；刻度保留 0°、30°、180°、210°、360°，均按实际角度定位，尤其保留 30°／210° 触发标记；它们只是参考，不是档位。窄轨道的两组标签上下错开，最窄布局也不隐藏触发角。角度读数预留固定宽度，避免位数变化使拖动轨道伸缩。

播放从当前角度连续运行到 360°；跨越 30°、180°、210° 时仅同步切换四块选中状态、电路和波形，不再自动暂停。暂停／继续保持当前角度；拖动会暂停以便观察。前后箭头和顶部四块仍能快速定位边界，完成时保持末段左极限显示，只有主动从头播放才归零。减少动态时仍不创建动画，主操作直接显示周期末，也可手动拖动观察。

动画时间保留浮点角度，独立于滑杆的 0.1° 输入精度，避免原生控件规范化反馈造成停播或跳动。UI 文案、课程规范和浏览器回归同步更新；没有更改电路资源、波形算术、题目或学习记录。最新浏览器测试在单次播放中检查跨越全部三个内部边界仍持续运行，并覆盖任意位置暂停后继续、鼠标／触摸任意位置拖动、连续多点移动、终点和生命周期。证据位于 `artifacts/conduction-continuous/`（忽略目录）。验收：检查 0 错误／警告，153 pass / 44 既有 skip / 0 fail，构建 41 页；21 组交互与 35 组紧凑布局浏览器验证通过，全部图形 provenance 输入与原始裁图保持不变。
