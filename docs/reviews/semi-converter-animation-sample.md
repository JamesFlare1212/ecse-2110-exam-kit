# 半控桥逐步动画小样

> 历史小样记录：用户确认后，Q4(a) 已按渐进增强方式正式接入。当前实现与验收见 [正式接入记录](semi-converter-integration.md)；下面保留原小样的范围与决策背景。

此小样回应 Q4(a) 波形图的逐步演示批注，仅放在 `scripts/samples/` 与忽略的 `artifacts/`，不替换正式静态 SVG，不改变题干、解答、来源、存储或网站交互契约。

## 使用

在已安装 `scripts/requirements-figures.txt` 的离线绘图环境中运行：

```bash
python3 scripts/samples/semi_converter_demo.py
# 打开 artifacts/semi-converter-animation/sample.html
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs bun scripts/samples/check_semi_converter_demo.mjs
bun test tests/semi-converter-animation.test.ts
```

`sample.html` 是完整、自包含、无外部请求的原型。`preview.html` / `preview-data.svg` 仅为 HTML 预览工具的本地图片内联传输封装；封装内容与原型完全相同，保留宿主主题样式。Noto Sans SC 的真实字形子集取自现有本地依赖，保留字体许可，不依赖系统中文字体。标准元件仍由 Schemdraw 生成。

## 范围与科学约定

- 只演示 Q4(a)：理想器件，α = 30°，已建立稳定连续负载电流，全部电压／电流归一化。不是非理想开关、电感动态或实时 SPICE 仿真。
- 保留原图的器件拓扑与标号：左腿上 S₁／下 S₂；右腿上 D₁／下 D₂；交流输入下线跨越左腿处**不连接**。将交流电源显式画在原有两输入端之间，仅用于独立教学小样。
- 导通顺序为 D₁+D₂、S₁+D₂、D₁+D₂、S₂+D₁；S₁ 的反向电压从 180° 过零后即开始，不延迟至 210°。
- 亮线与标记表示约定电流；i 箭头保留固定参考方向。负半周源电流为负，但负载电流仍向下。
- 播放本段、暂停、边界自动暂停、前后步进、区间选择、原生键盘可操作的角度滑杆；无自动启动。减少动态偏好下直接跳到区间边界，不运行移动标记。
- 直接根据理想开关状态与 KVL/KCL 推导，不新增公式表条目。原卷二极管标号的纠错沿用正式解答，不复制其错误导通配对。

## 验证

- 模型测试覆盖半开区间边界、KCL、瞬时功率、周期性、180°–210° 的反向电压及平均输出电压。
- 浏览器覆盖 390 / 728 px、明暗主题、所有区间、播放／暂停／自动停止、方向键操作、无页面横向溢出、零外部请求与减少动态偏好。
- 该原型不等于允许批量替换静态题图；是否接入正式解答，待用户确认教学形式后另行决定。
